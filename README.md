# Student Performance AI Prediction

An intelligent system using Random Forest Regression to predict academic outcomes based on multi-dimensional student data.

## Features
- **Modern UI**: SaaS-style dashboard using Streamlit.
- **Explainable AI**: Provides personalized recommendations based on input features.
- **Robust Pipeline**: Includes data scaling, encoding, and imputation.
- **Analytics**: Real-time visualization of model metrics.
