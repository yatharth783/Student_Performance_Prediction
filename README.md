# EduAI — Student Performance Intelligence

An AI-powered **Student Performance Prediction and Academic Analytics Dashboard** built using Machine Learning, Python, and Streamlit.

EduAI analyzes important academic factors such as attendance, study hours, previous scores, participation, and backlogs to predict a student's expected final performance.

---

## 📌 Overview

Student academic performance depends on multiple factors such as study habits, attendance, previous academic scores, participation, and backlogs.

**EduAI** uses Machine Learning to analyze these factors and generate an estimated final performance score.

The project also provides an interactive dashboard with:

- 📊 Performance metrics
- 🧬 Performance fingerprint
- 🎯 AI-based prediction
- 📈 Interactive charts
- 🔑 Key performance drivers
- 💡 Actionable academic insights

## Machine Learning

The model predicts the student's expected final score based on selected academic features.

### Input Features

| Feature | Description |
|---|---|
| Attendance | Student attendance percentage |
| Study Hours | Weekly study hours |
| Previous Score | Previous academic score |
| Participation | Academic participation percentage |
| Backlogs | Number of active backlogs |
